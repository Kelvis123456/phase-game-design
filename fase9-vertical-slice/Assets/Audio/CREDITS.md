# Créditos de audio

Todo el audio de este proyecto es de terceros con licencia libre, usado como
placeholder real (no silencio) hasta que haya presupuesto para audio original o FMOD
Studio para el stack final. Estos créditos son obligatorios para las pistas CC-BY y
deben mantenerse visibles en cualquier build público (ej. una pantalla de créditos).
